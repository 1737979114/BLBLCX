# 哔哩哔哩 · astrbot_plugin_bilibili

在群里查 B 站视频：搜关键词出卡片图，发链接/BV 号自动解析详情，还能看全站热门榜。

## 群里的用法

| 你说 | 机器人做什么 |
|---|---|
| `b站 罗翔 刑法` | 按关键词搜视频，出一张带封面的列表卡片 |
| `b站 BV1GJ411x7h7` | 直接查这条视频的详情卡片 |
| `b站 热门` / `b站热门` | 全站热门榜 |
| 回复 `3` | 看刚才搜索结果里的第 3 条详情（120 秒内有效） |
| 直接发 `https://b23.tv/xxxx` | 自动解析成详情卡片，不用敲指令 |
| 直接发 `BV1GJ411x7h7` | 同上 |

其他写法：`B站 罗翔`、`哔哩哔哩 罗翔`、`bili 罗翔`、`/b站 罗翔` 都能识别。
关键词带空格没问题——`b站 罗翔 刑法 全集` 会整个当成搜索词。

## 效果

- **搜索卡片**：封面缩略图 + 序号 + 时长角标 + 标题（两行截断）+ UP 主 + 播放/弹幕/时长/发布日期
- **详情卡片**：大封面 + 标题 + UP 主/分类/发布日期 + 播放/弹幕/点赞/收藏四宫格 + 简介三行 + BV 号和链接
- **热门榜**：同搜索卡片版式

图是本地用 Pillow 合成的（800px 宽），不走任何在线渲染服务，所以一定发得出来。

## 配置

WebUI → 插件管理 → 哔哩哔哩：

| 配置项 | 默认 | 说明 |
|---|---|---|
| 启用哔哩哔哩查询 | 开 | 总开关 |
| 搜索结果条数 | 8 | 1–10，条数越多卡片越长 |
| 发送方式 | card | `card` 图片卡片 / `text` 纯文字 |
| 搜索结果排序 | totalrank | 综合 / 播放量 / 最新 / 弹幕 / 收藏 |
| 自动解析群里的链接和 BV 号 | 开 | 关掉后只响应 `b站` 指令 |
| 搜完可以用序号看详情 | 开 | 关掉后搜索完就结束 |
| 序号有效期 | 120 秒 | 防群里正常聊天被误判 |
| 允许 AI 主动搜 B 站 | 开 | 用户和 AI 说「找 B 站上 XX 的视频」时，AI 自己调 |
| 同一用户冷却 | 3 秒 | 防刷屏 |
| 请求超时 | 10 秒 | |

## 实现说明

```
main.py        指令注册、消息分流、序号会话、AI 工具
bili_api.py    B 站接口封装（搜索 / 详情 / 排行 / 短链 / 封面下载）
bili_render.py Pillow 卡片渲染
```

调用的都是哔哩哔哩**对外公开的 Web 接口**：

- `GET /x/web-interface/search/type` 搜索
- `GET /x/web-interface/view` 视频详情
- `GET /x/web-interface/ranking/v2` 排行榜
- `GET /x/frontend/finger/spi` 取 `buvid3` 降低被风控概率

不登录、不带账号 cookie、不下载视频流、不绕过任何权限——拿到的全是网页上本来就能看到的信息。

### 关于风控

B 站会对高频请求返回 `-352` / `-412`。插件已经做了两件事：自动带 `buvid3` cookie；命中风控时给用户一句「被风控拦了，过几分钟再试」，而不是甩一串报错。

日常群里用不会触发。真被拦了等几分钟即可，不用改配置。

### 已知边界

- 搜索结果里混着的付费课程/推广卡片没有 BV 号，点不进详情，插件会自动过滤掉
- 私密视频、审核中的视频、已删除的视频会给出对应提示
- 封面图有防盗链，下载时必须带 Referer，已处理
- 没装中文字体时会退化成方块字（Windows 自带微软雅黑，正常不会遇到）

## 装在哪

```
C:\Users\Administrator\data\plugins\astrbot_plugin_bilibili\
```

AstrBot 启动时扫描 `data/plugins/`，**放进去重启就生效**，不需要在 WebUI 里额外安装。

卡片图临时落在 `data/plugin_data/astrbot_plugin_bilibili/`，超过一天的会自动清理。
